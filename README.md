# Repair Job Tracker

A lightweight web application built for managing hardware repair workflows, customer records, and status updates using procedural PHP and SQLite.

## Stack
- **Backend:** PHP 8 (Procedural), SQLite3
- **Frontend:** HTML5, CSS3, Vanilla JavaScript

## Features
- Full CRUD operations for repair lifecycle management.
- Dynamic input validation with CSS state classes.
- Server-side edge case enforcement (notes & cost required for completion).
- Asynchronous browser-side detail preview via modal overlay.
